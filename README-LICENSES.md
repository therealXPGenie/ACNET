# ACNET licensing bundle

Copy these files into the root of the ACNET GitHub repository/release.

- `LICENSE` — GPL-3.0 project license already used by the ACNET repository
- `ACKNOWLEDGEMENTS.md` — credits, thanks, and attribution
- `NOTICE` — compact release notice
- `THIRD_PARTY_LICENSES/` — third-party license texts and notices
- `ACNET_R70_CYRINX_GGWAVE_LICENSED.html` — standalone build with embedded
  attribution comments
- `SHA256SUMS.txt` — release hashes

The licensing pass changes only comments/attribution in the HTML; it does not
intentionally change modem or UI behavior.
