# ACNET
Audio Communication Network
Turn your sound card into a network adapter. An acoustic internet built for off-grid telecommunication.

Acnet is an in-browser system that uses 4-FSK/2-FSK and SSTV (PD290) over an audio channel. The first of its kind—an inexpensive and simplified HTTPS-over-sound solution. Envisioned to help during internet blackouts, it works like a tactical communication network.
